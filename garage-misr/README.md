# جراج مصر (Garage Misr)

لعبة ألغاز: العربيات المركونة في الجراج بتكوّن رسمة، وإنت بتبعت تريلات ملونة تشيل العربيات
اللي طريقها مفتوح للبوابة لحد ما الجراج يفضى.

## تشغيلها على اللاب
1. نزّل **Godot 4.3** (النسخة العادية مش .NET) من godotengine.org.
2. افتح Godot ← Import ← اختار `garage-misr/project.godot`.
3. أول مرة هياخد ثواني يعمل Import للخط والملفات.
4. دوس **F5** (أو زرار ▶ فوق على اليمين). اللعبة بتفتح على آخر مرحلة كنت فيها.

جوه اللعبة:
- دوس على أي تريلا في الطوابير تحت عشان تدخل رصيف.
- `›` و`‹` فوق: المرحلة اللي قبل واللي بعد (للاختبار).
- `تاني؟` إعادة، `١×/٢×` السرعة، `تلميح` يعلّم على أحسن تريلا دلوقتي.
- المراحل 1–5 تعليمية: التلميح شغال لوحده.

## الاختبارات
من Godot: افتح لوحة GUT تحت ودوس Run All، أو من الترمينال:

    GODOT=/path/to/godot ./run_tests.sh

## الملفات
- `engine/` المحرك (منطق خالص) — القواعد في `docs/RULES.md`.
- `levels/001.json` … `100.json` المراحل، وكل مرحلة معاها حلها.
- `tools/` المولّد والمدقق والمحاكي والبوتات — الشرح في `docs/LEVEL_GENERATION.md`.
- `reports/` تقارير الصعوبة (`after.csv`, `before.csv`, `summary.md`).
- `scenes/game.tscn` شاشة اللعب، `view/garage_view.gd` رسم الجراج.
- الخط: Cairo (رخصة SIL OFL، في `fonts/Cairo-OFL.txt`).
